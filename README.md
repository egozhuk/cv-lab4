# cv-lab4

Что делает:

Готовит датасет: детекция лица MTCNN + кроп (+ опциональное выравнивание по глазам).
Обучает безусловный WGAN-GP для генерации лиц.
Преобразует ту же архитектуру в условную (по признаку Male) и обучает cWGAN-GP.
Считает метрики FID и Inception Score.
Строит кривые обучения и показывает сэмплы.
